# Pre-computed reference outputs

This directory is a copy of the actual outputs produced by the scripts in
`code/` when run on the full pipeline. It is **not required** to reproduce
the paper (everything here is regenerated by the commands in the top-level
`README.md`), but it is included so a reader can check any specific number,
table, or figure cited in the paper directly against its source file without
re-running anything. Total size ~5.5 MB.
